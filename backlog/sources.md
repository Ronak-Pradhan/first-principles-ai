# Weekly Discovery Sources

The goal is NOT to find the newest papers.

The goal is to discover high-quality mathematical ideas suitable for a
First Principles implementation.

Always search in priority order.

---

# Tier 1 — Peer Reviewed Research (Highest Priority)

Prefer accepted papers, oral presentations, spotlight papers and award papers.

Search:

- NeurIPS
- ICML
- ICLR
- CVPR
- ICCV
- ECCV
- ACL
- EMNLP
- AAAI
- JMLR
- TMLR
- OpenReview Accepted Papers
- ISMIR
- ICASSP
- RecSys

Avoid recommending papers that have no clear mathematical mechanism.

---

# Tier 2 — Research Labs

Search technical blogs from

- OpenAI
- Anthropic
- Google DeepMind
- Google Research
- Meta AI
- Microsoft Research
- NVIDIA Research
- Amazon Science
- Apple ML Research
- Netflix Tech Blog
- Spotify Research

Ignore:

- Product launches
- API announcements
- Benchmarks
- Marketing names

Extract only the underlying mechanism.

---

# Tier 3 — Community Sources

Use carefully.

- Hugging Face Blog
- Hugging Face Papers
- Sebastian Raschka
- Lilian Weng
- Chris Olah
- Karpathy

Extract mechanisms.

Ignore tutorials unless they introduce
an important mathematical concept.

---

# Tier 4 — arXiv

Only recommend if ONE of the following is true

- Accepted to a major venue
- Widely adopted by industry
- Receiving sustained discussion across multiple labs
- Likely to become foundational

Avoid random weekly uploads.

---

# Discovery Policy

Prefer discovering mechanisms rather than paper names.

Good examples

- Rotary Position Embeddings
- Speculative Decoding
- Multi Query Attention
- RMSNorm
- Mixture of Experts Routing

Avoid recommending

- Benchmarks
- Datasets
- Tiny optimizer tweaks
- Hyperparameter tricks
- Hardware optimizations
- Prompt engineering techniques
- Product features

---

# Diversity Requirement

Emerging recommendations should cover multiple domains whenever possible.

Target domains include

- Transformers
- Vision
- Diffusion
- Reinforcement Learning
- Representation Learning
- Graph ML
- Recommendation Systems
- Audio
- Music AI
- Quantitative Finance
- World Models
- Causal Inference

Do not repeatedly recommend Transformer variants if other domains have equally strong candidates.

---

# Final Question

Before recommending any topic, ask:

"If the author could only build ONE module this week, would this topic maximize the long-term value of the First Principles AI repository?"

If the answer is not clearly YES, reject it.
